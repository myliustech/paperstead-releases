# Paperstead releases

Desktop downloads for [Paperstead](https://paperstead.com) — notes that work offline, on every device.

- **Mac:** [Paperstead-mac.dmg](https://github.com/myliustech/paperstead-releases/releases/latest/download/Paperstead-mac.dmg)
- **Windows:** [Paperstead-win.exe](https://github.com/myliustech/paperstead-releases/releases/latest/download/Paperstead-win.exe)

The app updates itself automatically.
